# Finance

## Description

A web application built with Flask that allows users to look up stock prices, buy and sell stocks, and manage a virtual investment portfolio.
The application uses a database to store user accounts, transactions, and portfolio information, while integrating stock price data to provide current market values.
It was developed as part of Harvard's CS50x course to practice web development, databases, authentication, and API integration.


## Features

- User registration and login
- Stock price lookup
- Buy and sell stocks
- Portfolio tracking
- Transaction history
- Cash balance management

## Technologies

- Python
- Flask
- SQLite
- HTML
- CSS
- Jinja2
